TDSpeed / Rockbox Pitch Plugin 0.4.2-rc.1

Open TDSpeedPreview.exe. Audio starts dry; Enable processing applies pitch/effects. Closing hides to tray; Exit restores Windows audio. Audio settings selects a usable cable and speakers. Mix 100% is fully wet. See README.md and docs for controls, troubleshooting, build and release gates.

This RC updates the TDSpeed Preview application and preserves its settings and plugin identity. Only one TDSpeed can forward audio at a time.

VB-CABLE is by VB-Audio Software, donationware: https://vb-audio.com/Cable/ . The installer bundles the original signed standard driver package unchanged; existing cable drivers are never uninstalled. If the portable app cannot find a usable cable, use the installer.

The application/installer are unsigned. VB-CABLE is vendor signed; the app is not trusted-signed unless explicitly stated in the release signature report. See the validation report for tested and outstanding checks.

Song render: load/drop a song, Play and tweak, Render from start, then Save As AAC (320 kbps target) or FLAC. FLAC needs no extra software. AAC requires FFmpeg on PATH: winget install --id Gyan.FFmpeg -e . Restart the app afterward. The VST3 also lets you drag the rendered waveform into a DAW.
